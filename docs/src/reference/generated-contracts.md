# Generated plugin contracts

This page is generated by [`examples/contract_reference/main.rs`](../../../examples/contract_reference/main.rs) from `App::plugin_contracts()` and typed `ConfigDescription` metadata. Do not edit it by hand; `cargo run --example contract_reference > docs/src/reference/generated-contracts.md` refreshes it, and CI rejects drift. It intentionally records mechanical API facts only; scientific interpretation belongs in the surrounding hand-written reference and tutorials.

The sample registers Grass built-ins plus `oscillator_demo`, demonstrating the same downstream-library path: implement `Plugin`, return declarative metadata, and add the plugin to a documentation probe. Ports are application-owned; `oscillator_demo` advertises its stable `PositionPort<Source>` payload for that seam.
